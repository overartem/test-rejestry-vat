# Отступы, размеры и сетка

Источник правды — `css/tokens.css`. Разовые значения отступов в CSS не используются — только токены
(или `calc()` из них).

## Шкала отступов

| Токен | Значение | Типичное применение |
| --- | --- | --- |
| `--sp-px` | 1px | Зазоры между пунктами меню, вертикальные поля бейджей |
| `--sp-0-5` | 0.125rem | Внутренние отступы сегментированного переключателя, мелкие сдвиги иконок |
| `--sp-1` | 0.25rem | Плотные группы (бейдж: иконка + текст) |
| `--sp-1-5` | 0.375rem | Горизонтальные поля бейджей, `kbd` |
| `--sp-2` | 0.5rem | Элементы внутри одной группы |
| `--sp-3` | 0.75rem | Поля ввода, строки списков |
| `--sp-4` | 1rem | Внутренние отступы блоков |
| `--sp-5` | 1.25rem | Поля диалогов |
| `--sp-6` | 1.5rem | Между карточками |
| `--sp-8`, `--sp-10`, `--sp-12` | 2 / 2.5 / 3rem | Между секциями, отступы под иконки в полях |
| `--sp-20` | 5rem | Место под плавающий переключатель демо-состояний |

Флюидные: `--gutter` (поля страницы), `--pad-card` (карточки), `--pad-page-top` (верх страницы),
`--pad-state` (пустые состояния и ошибки).

Правило ритма: между секциями отступ больше, чем между элементами внутри секции.

## Размеры

| Токен | Значение | Роль |
| --- | --- | --- |
| `--control-h` / `--control-h-sm` | 2.5 / 2rem, на сенсорных экранах 2.75rem | Высота кнопок и полей (цель нажатия ≥ 44px на touch) |
| `--icon-sm` / `--icon-md` / `--icon-lg` | 0.95 / 1.125 / 1.375rem | Иконки |
| `--header-h`, `--chrome-h` | — | Высота шапки и всей липкой зоны (для sticky-панели выбора) |
| `--content-max` | 78rem | Максимальная ширина контента |

## Скругления и тени

`--radius-sm/md/lg/xl/pill` — единая шкала скруглений. `--shadow-sm/md/lg` — мягкие тени низкой
непрозрачности; тени и рамки вместе в полную силу не используются.

## Адаптивность

- Страница: `@media` 40rem (телефон) и 24rem (очень узкие экраны).
- Таблица: `@container data` — меньше 56rem превращается в карточки.
- Фильтры и диалоги на телефонах — bottom sheet.
