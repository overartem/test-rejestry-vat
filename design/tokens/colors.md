# Цвета

Источник правды — `css/tokens.css`. Все цвета заданы в `oklch()` через `light-dark()`: первое значение — светлая тема,
второе — тёмная. Тёмная тема — отдельно подобранная шкала, а не инверсия. Цвета вне токенов в CSS не используются
(исключение — `print.css`, где печать идёт в чёрно-белом).

Палитра взята с референсов: один акцент (teal), остальное — серая шкала и статусные цвета.

## Акцент

| Токен | Роль |
| --- | --- |
| `--c-primary` | Основные кнопки, выбранное состояние, ссылки, фокус |
| `--c-primary-hover` | Hover основной кнопки |
| `--c-primary-soft` / `--c-primary-border` | Фон и рамка выбранных чипов, бейджа «Gotowe» |
| `--c-on-primary` | Текст на `--c-primary` |

## Нейтральные

| Токен | Роль |
| --- | --- |
| `--c-bg` | Фон страницы |
| `--c-surface` | Карточки, диалоги, поповеры |
| `--c-surface-2` / `--c-surface-3` | Вложенные зоны (блок итогов, шапка таблицы), skeleton |
| `--c-text` | Основной текст (не чисто чёрный) |
| `--c-text-muted` | Вторичный текст, подписи |
| `--c-text-subtle` | Placeholder, метаданные |
| `--c-border` / `--c-border-strong` | Разделители / рамки полей ввода |
| `--c-overlay` | Подложка модальных окон |

## Статусы

Только для статусов, всегда вместе с иконкой и текстом — никогда только цветом.

| Набор | Значение |
| --- | --- |
| `--c-warning*` | «Wymaga potwierdzenia / konfiguracji», демо-режим |
| `--c-danger*`, `--c-on-danger` | Ошибки, отрицательные суммы, счётчик уведомлений |
| `--c-info*` | Информационные подсказки, статус KSeF «W trakcie» |
| `--c-success*` | Алиас акцента: «Gotowe», «Zweryfikowane» |

Каждый набор: базовый цвет (текст/иконка), `-soft` (фон), `-border` (рамка).

## Прочее

| Токен | Роль |
| --- | --- |
| `--c-accent-violet` | Только цвет пользовательских этикеток |
| `--c-inverse`, `--c-on-inverse`, `--c-inverse-primary`, `--c-inverse-danger` | Toast-уведомления (инверсная поверхность) |

## Контраст (WCAG AA)

Замерено в браузере: основной и вторичный текст, бейджи и кнопки — от 5.4:1 до 10:1 в обеих темах;
placeholder — не ниже 4.5:1.
