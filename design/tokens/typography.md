# Типографика

Источник правды — `css/tokens.css`. Шрифт **Inter** (как на референсах), моноширинный — системный
(`--font-mono`) для NIP, идентификаторов и номеров KSeF. Цифры в таблицах и итогах — `tabular-nums`.

## Шкала

| Токен | Размер | Роль |
| --- | --- | --- |
| `--fs-xs` | 0.75rem | Подсказки, бейджи, счётчики |
| `--fs-sm` | 0.8125rem | Подписи полей, метаданные, шапка таблицы |
| `--fs-md` | 0.875rem | Текст интерфейса, ячейки таблицы, кнопки |
| `--fs-base` | 0.9375rem | Основной текст, имя контрагента |
| `--fs-lg` | 1–1.125rem (fluid) | Заголовки карточек |
| `--fs-xl` | 1.125–1.375rem (fluid) | Заголовки секций и диалогов |
| `--fs-2xl` | 1.5–2.25rem (fluid) | Заголовок страницы (`h1`) |
| `--fs-kpi` | 1.125–1.5rem (fluid) | Суммы Netto / VAT / Brutto |

## Правила

- Иерархию сначала строим весом и цветом (`--c-text` → `--c-text-muted`), и только потом размером.
- Один `h1` на страницу; дальше `h2` → `h3` без пропусков.
- В метриках число крупное и жирное, подпись над ним — `--fs-sm` и `--c-text-muted`.
- Крупные «hero»-заголовки внутри плотных экранов не используем.
