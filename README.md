# TestCompany · Rejestry i VAT — прототип редизайна

Рабочий адаптивный прототип обзорной страницы **Obszary księgowe** и экрана **Rejestry i VAT**.
Чистые HTML, CSS и ES-модули — без фреймворков, без сборки, без зависимостей.

## Локальный запуск

```bash
npx serve -s . -l 5173
# открыть http://localhost:5173
```

Флаг `-s` (режим SPA) обязателен: маршруты вроде `/obszary/rejestry-vat` обрабатывает клиентский роутер.
Открыть `index.html` двойным кликом (`file://`) не получится — ES-модулям и маршрутам нужен сервер.

### Почему `/` открывается как `/obszary`

- **URL повторяет навигацию.** Хлебные крошки — «Ewidencje / Obszary księgowe / Rejestry i VAT», поэтому
  обзор живёт на `/obszary`, а области — на `/obszary/rejestry-vat`, `/obszary/ksiegowania` и т. д.
- **Без дублей.** Отдельной страницы для корня нет, поэтому `/` просто перенаправляет на `/obszary`
  (одна строка в `js/main.js`), а не показывает тот же экран по двум адресам.
- **Прямые ссылки работают.** Любой адрес можно открыть сразу, например
  `/obszary/rejestry-vat?r=purchase&y=2026&m=10` — откроется нужный регистр, период и фильтры.
  Ссылкой можно поделиться, кнопки «назад/вперёд» работают.

## Деплой

Залить папку на GitHub и импортировать репозиторий в Vercel с пресетом **Other**
(без команды сборки, выходная директория `.`). В `vercel.json` уже настроены SPA-rewrite, заголовки безопасности и кеширование.

## Что посмотреть

| Где | Что |
| --- | --- |
| `/obszary` | Карточка периода с диалогом настройки, индикатор готовности, карточки областей с раскрываемыми условиями запуска |
| `/obszary/rejestry-vat` | Регистры продаж и закупок, выбор периода, поиск, фильтры, таблица, итоги, групповые действия |
| **Stany demo** (слева внизу) | Принудительно включает состояния *загрузка*, *нет данных* или *ошибка сервера* — также через `?state=loading\|empty\|error` |
| Шапка | Светлая/тёмная тема (по умолчанию следует системной), уведомления, меню аккаунта с переключением языка PL/EN |

Демо-данные генерируются детерминированно (PRNG с фиксированным seed, корректные контрольные суммы NIP).
Период по умолчанию — октябрь 2026; декабрь 2026 намеренно пустой, ноябрь 2026 заполнен частично.

## Решения по UX/UI

- **Одна понятная задача на экране.** Тип регистра — сегментированный переключатель со счётчиками документов,
  период — один пикер со стрелками «предыдущий/следующий месяц», поиск всегда на виду. Редко используемое
  (фильтры, колонки, этикетки, печать, CSV) спрятано за кнопкой *Filtry* и меню *⋯* — ни одно поле
  или действие исходного экрана не потеряно.
- **Сначала итоги.** Netto / VAT / Brutto показаны над таблицей, разбивка по ставкам VAT сворачивается.
- **Состоянием можно поделиться.** Регистр, период, поиск, фильтры, сортировка и страница хранятся в URL;
  кнопки «назад/вперёд» браузера работают.
- **Продуманы все состояния:** skeleton при загрузке, пустой период (с переходом к ближайшему периоду с данными),
  «ничего не найдено» по фильтрам (сброс в один клик), ошибка сервера с повтором, страница 404.
- **Адаптивность по контейнеру, а не только по viewport.** Таблица превращается в карточки, когда её контейнер
  уже 56rem; фильтры на телефонах открываются как bottom sheet; всё работает вплоть до 320px (iPhone SE).
- **Навигация по областям на телефоне** прокручивается горизонтально. Что пунктов больше, подсказывают
  затемнения по краям (появляются только с той стороны, где есть скрытые пункты), активный пункт
  всегда по центру. Один раз за сессию список слегка сдвигается, чтобы показать, что его можно листать;
  после первой ручной прокрутки подсказка больше не показывается, при `prefers-reduced-motion` её нет.
  Чтобы увидеть её снова, удалите `rv:navHintSeen` из localStorage.
- **Поиск** очищается крестиком (виден, пока в поле есть текст) или клавишей `Esc`.
- **Доступность (WCAG 2.2 AA).** Семантические landmarks, skip link, ARIA-вкладки со стрелками, `aria-sort`,
  меню с roving focus, возврат фокуса после диалогов, live-регионы для результатов и уведомлений,
  ошибки форм у полей (`aria-invalid` + `aria-describedby`). Зоны нажатия не меньше 24px, на сенсорных
  экранах — 44px; фокус не прячется под липкой шапкой (`scroll-padding`); учёт `prefers-reduced-motion`
  и `prefers-color-scheme`. Горячие клавиши: `/` — фокус в поиск, `Esc` — очистить поиск.
- **Локализованное форматирование** через `Intl` (суммы в PLN, даты, польские правила множественного числа).
  Суммы хранятся в грошах (целые числа).
- **Экспорт.** CSV с разделителем `;` и UTF-8 BOM корректно открывается в Excel; печать формирует отдельный отчёт A4.

## Использованные возможности платформы

CSS cascade layers, нативный nesting, `oklch()` + `light-dark()`, container queries, `:has()`, `@starting-style`,
anchor positioning (с JS-фолбэком), `::details-content`, scroll-driven animations + `@property`
(затемнения навигации); нативный `<dialog>`, Popover API, `<search>`,
View Transitions, History API.

## Структура

```
index.html            оболочка приложения + SVG-спрайт иконок
css/                  токены, base, layout, компоненты, страницы, печать
js/main.js            маршруты и инициализация
js/router.js          роутер на History API
js/store.js           мини-store, localStorage и работа с URL
js/i18n.js, locales/  словари PL / EN
js/api.js             имитация API с задержкой и принудительными состояниями
js/data/              демо-данные и модель областей/условий
js/utils/             DOM-хелперы, форматирование (Intl), экспорт CSV
js/components/        шапка, диалоги, поповеры, таблица, фильтры, выбор периода…
js/views/             страницы
design/tokens/        описание токенов: цвета, типографика, отступы
```

Дизайн-токены живут в `css/tokens.css`, а их роли и правила использования описаны в `design/tokens/*.md`.
